# student-performance-prediction-using-linear-regression-
This project aims to predict students’ academic performance based on various factors such as study hours, previous grades . Using Linear Regression, a fundamental supervised learning algorithm.
The main goal is to identify key factors that influence academic outcomes and to create a model that can accurately forecast a student’s performance. This helps teachers, parents, and institutions take proactive steps to improve learning outcomes and provide personalized support to students at risk of underperforming.

Objectives:
To analyze and understand factors affecting student performance.
To apply Linear Regression to predict student grades or test scores.
To evaluate model performance using metrics like R² score, Mean Absolute Error (MAE), and Root Mean Squared Error (RMSE).
To visualize the relationship between study factors and performance using data visualization techniques.

Tools and Technologies:
Programming Language: Python
Libraries: pandas, numpy, matplotlib, seaborn, scikit-learn
Algorithm: Linear Regression

Expected Outcome:
A predictive model that can estimate a student’s academic performance based on given input features, along with insights into the most influential factors affecting student success.
